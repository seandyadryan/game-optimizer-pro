# Kebijakan Privasi — Game Optimizer PRO

Tanggal berlaku: 30 September 2026<br>
Versi HTML dwibahasa untuk dibaca dan diterbitkan tersedia di [privacy-policy.html](../privacy-policy.html). Terbitkan melalui hosting statis sebelum memasukkan URL publik ke Google Play Console.

Pengembang: seandyadryan / Deploy Dulu Pulang Nanti  
Aplikasi: `com.deploydulupulangnanti.gameoptimizerpro`

Game Optimizer PRO tidak mengumpulkan atau mengirim data pribadi ke server. Aplikasi tidak memiliki akun, iklan, analitik, SDK pelacak, maupun izin Internet.

## Informasi yang diproses di perangkat

- Baterai, suhu baterai, kondisi termal, RAM, ruang penyimpanan, mode hemat daya, dan jenis/status koneksi untuk dashboard.
- Nama, package, dan ikon aplikasi yang dapat diluncurkan untuk pustaka game. Daftar dan ikon dibaca dari perangkat, tidak dikirim ke pihak lain.
- Pilihan bahasa disimpan di perangkat. Terjemahan tersedia secara offline tanpa layanan penerjemah eksternal.
- Game pilihan, profil rekomendasi, serta waktu mulai dan selesai sesi yang dicatat manual. Maksimal 100 sesi terakhir disimpan.

Izin `ACCESS_NETWORK_STATE` digunakan untuk menampilkan status koneksi, tanpa membaca lalu lintas jaringan. Aplikasi membuka halaman pengaturan sistem atas tindakan pengguna. Pengguna sendiri yang menentukan perubahan pengaturan.

## Penyimpanan dan penghapusan

Data disimpan di penyimpanan privat aplikasi. Cadangan cloud Android dinonaktifkan. Riwayat dapat dihapus melalui menu Pengaturan. Semua data lokal dapat dihapus melalui pengaturan aplikasi Android atau dengan menghapus instalasi aplikasi.

## Berbagi data dan anak-anak

Tidak ada data yang dijual atau dibagikan. Aplikasi tidak meminta identitas atau informasi anak-anak.

## Perubahan dan kontak

Kebijakan ini akan diperbarui jika fitur atau praktik data berubah. Pertanyaan dukungan dapat disampaikan melalui [halaman dukungan GitHub](https://github.com/seandyadryan/game-optimizer-pro/issues). Informasi yang Anda kirim sendiri di GitHub mengikuti kebijakan privasi GitHub; hindari memasukkan data sensitif dalam issue publik.
